# automated-testing-framework

Repository-specific rules for people and agents working here, code review
included. Where this file and the shared engineering context in
`.github/review-context/` disagree, this file decides for this repository.

## Pull request titles

This repository keeps conventional-commit prefixes in PR titles, for example
`fix(smoke): …`, `feat(regression): …`, or `test(ilm#<epic>): …` from the test
agent. The shared rule against title prefixes does not apply here, so a
prefixed title is not a finding.
